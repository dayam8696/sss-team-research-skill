# SSS Team Research Skill

A skill that helps you plan, write, structure and review research papers, and make editable figures for them, in the house style of the SSS research team. It covers four paper types: empirical studies, systematic and literature reviews, bibliometric analyses and position papers.

## What it does
- Writes or improves any section: title, abstract, introduction, related work, methodology, results, discussion, limitations, conclusion.
- Designs methodology: research questions, PRISMA protocols and search strings, bibliometric pipelines and experimental checklists.
- Makes editable figures as draw.io XML: methodology pipelines, double-stage search and selection diagrams, PRISMA flows and taxonomy maps. Also gives matplotlib code for results charts.
- Reviews drafts like a journal reviewer, with a severity-ranked list of fixes.

The skill never invents numbers or references. Missing facts become visible placeholders such as `[CITE: ...]` and `[DATA: ...]`.

## What this plugin contains
Markdown instructions and reference guides only. No scripts, servers, hooks or network calls. The full edition with figure-generator scripts and the source code is at https://github.com/dayam8696/sss-team-research-skill.
